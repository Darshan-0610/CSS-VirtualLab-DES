Core theoretical concepts

Block size

DES operates on 64-bit blocks. Messages longer than one block are split into 8-byte blocks; this lab uses ECB-style independent DES blocks with PKCS#7 padding for teaching simplicity.

Effective key size

The external key is 64 bits. Eight parity positions are discarded by PC-1, leaving 56 bits that influence the round keys.

Feistel network

Each round sets Ln = Rn-1 and Rn = Ln-1 XOR F(Rn-1, Kn). Decryption uses the same round function with subkeys in reverse order.

S-boxes

Eight fixed 6→4 bit S-boxes introduce non-linearity. Their outputs feed the P-box permutation before the round result is XORed with the left half.

Key schedule

PC-1 removes parity bits, C and D halves are circularly shifted according to the DES shift schedule, and PC-2 selects 48-bit round subkeys.

Avalanche effect

A one-bit input change should produce a large, apparently unpredictable output change. For a 64-bit idealized block output, roughly half the bits changing is the expected qualitative behavior.

Primary standards and reading

  2. NIST SP 800-17 — Modes of Operation Validation System (MOVS), including DES known-answer testing guidance.

DES is retained here as an educational algorithm. NIST withdrew FIPS 46-3 in 2005 because DES no longer provided sufficient security for current protection needs.
