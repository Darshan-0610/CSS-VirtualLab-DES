DES Encryption & Avalanche Effect

Cryptography • TE Comp B

Aim & Objectives

To implement the Data Encryption Standard (DES) algorithm for encrypting and decrypting a message, and to demonstrate the avalanche effect by observing ciphertext changes from a single-bit input flip.

Theory

DES is a symmetric-key block cipher published by NIST (FIPS PUB 46). Key characteristics include:

  • Block Size: 64 bits (Plaintext is processed in 64-bit blocks).
  • Key Size: 64 bits total, but only 56 bits are effective (8 bits are used for parity).
  • Structure: A 16-round Feistel Network.

Core Components:

  • Initial/Final Permutations (IP / FP): The 64-bit block is permuted before the first round and after the 16th round.
  • Feistel Round: The 64-bit block is split into Left (L) and Right (R) 32-bit halves. For each round: L(n) = R(n-1) and R(n) = L(n-1) ⊕ f(R(n-1), K_n).
  • The f-function: Expands R to 48 bits (E-box), XORs with the 48-bit round subkey, passes through 8 substitution boxes (S-boxes) to shrink back to 32 bits, and finally permutes (P-box).
  • Key Schedule: The 64-bit key is reduced to 56 bits (PC-1), split into two 28-bit halves, left-shifted according to a specific schedule, and compressed to 48-bit subkeys (PC-2) for each round.

The Avalanche Effect: A desirable property of cryptographic algorithms where a small change in the input (e.g., flipping 1 bit of plaintext or key) results in a drastic change in the output. For a strong cipher like DES, flipping 1 input bit should flip approximately 50% of the ciphertext bits.

Experiment Procedure

  1. Input Plaintext: Enter the message you want to encrypt. It will be converted into a 64-bit block (padded or truncated if necessary).
  2. Input Key: Provide a secret key. The system will normalize this into a 64-bit (8-byte) key for DES.
  3. Encrypt: The system applies the Initial Permutation (IP), 16 Feistel rounds, and the Final Permutation (FP) to generate the Ciphertext.
  4. Verify / Decrypt: Use the same key to decrypt the Ciphertext and verify that it matches the original Plaintext.
  5. Avalanche Demonstration: Navigate to the Avalanche tab, select a specific bit to flip in the plaintext or key, and observe the resulting changes in the final ciphertext bits.
